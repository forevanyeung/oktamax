Admin-managed policies

Set up Okta Max for every admin at once. Settings pushed by Chrome policy apply as soon as the extension loads, and admins can't change them.

Available settings

Key Type What it does
chatServerUrl string Base URL of your chat server, for example https://oktamax.example.com. The assistant uses it, and the popup shows it read-only. An empty string turns the assistant off.

Set it

  1. Google Admin console

    Go to Devices › Chrome › Apps & extensions › Users & browsers, select Okta Max, and under Policy for extensions paste: 

    { "chatServerUrl": "https://oktamax.example.com" }

  2. Intune, Jamf or Group Policy

    Set the same chatServerUrl key under Okta Max's extension policy. The schema is managed_schema.json.

  3. Check it

    Open chrome://policy and click Reload policies. Okta Max's popup shows the server URL and doesn't let admins edit it.

No extra permission prompt. Chrome doesn't ask admins to allow the server set by policy. The example server's CORS policy already allows the extension.
